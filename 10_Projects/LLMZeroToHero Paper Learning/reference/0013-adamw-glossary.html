Core terms

English term中文解释Lesson 0013 中的精确定义与边界
objective / loss优化器试图最小化的目标函数Data loss 记作 \(f_t(\theta)\)；加入 L2 penalty 后变为 regularized objective \(\widetilde f_t(\theta)\)。
regularization在训练数据之外加入解的偏好用来影响多个可拟合解之间的选择；它不等于训练误差本身，也不自动保证更好的 generalization。
L2 regularization按参数平方和惩罚大 parameter norm在 objective 中加入 \(\frac{\lambda'}{2}\lVert\theta\rVert_2^2\)，其 gradient contribution 为 \(\lambda'\theta\)。
weight decay在 parameter update 中直接施加乘性收缩原始形式为 \(\theta_{t+1}=(1-\lambda)\theta_t-\alpha\nabla f_t(\theta_t)\)；它不是给 objective 加 penalty 的定义。
inductive bias数据本身未决定时采用的解选择偏好Weight decay 倾向 parameter norm 较小的解；在有 normalization 或 scale invariance 时，不能直接推出对应函数更简单。
parameter norm参数向量大小的度量本课使用 L2 norm \(\lVert\theta\rVert_2\)。Parameter norm 变小与 data loss 变小是两个不同目标。
parameter iterate一次更新得到的参数状态记作 \(\theta_t\)。Proposition 1 的“等价”指相同起点和系数换算下得到相同的逐步 iterate。
parameter trajectory连续 parameter iterates 形成的更新轨迹若每一步的 \(\theta_t\) 都相同，则两种算法 parameter-trajectory equivalent；这不表示它们的定义或 objective 相同。
adaptive preconditioner根据 gradient history 逐坐标缩放更新Adam 中写作对角矩阵 \(M_t\)。不同 coordinates 通常有不同缩放，因此 \(M_t\neq kI\)。
coupled L2 regularization / L2-Adam把 L2 term 放进 Adam gradient path\(\lambda'\theta\) 会依次进入 \(g_t\)、\(m_t\)、\(v_t\) 并受到 \(M_t\) 的逐坐标作用。
decoupled weight decay / AdamW把 decay 从 adaptive gradient path 中分离Moments 只聚合 data gradient；decay 直接作用于 parameters，不经过 \(m_t\)、\(v_t\) 或 \(M_t\)。
first momentgradient 的指数移动平均记作 \(m_t\)，保留 signed direction history；AdamW 中不聚合 weight-decay term。
second raw momentsquared gradient 的指数移动平均记作 \(v_t\)，记录 squared magnitude history；不是 centered variance。

Symbols

Symbol含义不要混淆
\(\alpha\)learning rate控制 gradient update 的全局尺度；不是每步 decay rate。
\(\lambda\)weight-decay rateLesson 的 Proposition 1 语境下，它直接决定 \((1-\lambda)\theta_t\)。
\(\lambda'\)L2 penalty coefficient标准 SGD 下要与 decay rate \(\lambda\) 等价，需满足 \(\lambda'=\lambda/\alpha\)。
\(M_t\)Adam 的 per-coordinate preconditioner它随 step 和 coordinate 变化，通常不是常数倍单位阵 \(kI\)。
\(m_t,v_t\)Adam 的 first 与 second raw moment stateL2-Adam 的 penalty 会进入这些 states；AdamW 的 decay 不进入。

不要混淆

不要混为一谈关键区别
L2 regularization vs weight decay前者修改 objective，后者修改 update rule；只在受限条件下 parameter-trajectory equivalent。
等价定义 vs 等价 iterateProposition 1 只证明经过系数换算后的逐步更新相同，没有把两种机制定义成同一个概念。
单独使用 vs 同时使用标准 SGD 下通常把二者视为替代实现；同时启用会叠加收缩，形成重复正则作用。
smaller parameter norm vs lower data lossDecay 施加的是解选择偏好；data gradient 才直接响应当前 data loss。
L2-Adam vs AdamWL2-Adam 让 penalty 经过 adaptive path；AdamW 让 decay 直接作用于 parameters。
