Core terms

English term中文解释Lesson 0014 中的精确定义与边界
computational budget / training budget计划执行的训练工作量本课主要用 epochs \(T\) 与 batch-pass count \(N=BT/b\) 表达；不是 FLOPs 的完整定义。
batch pass处理一个 minibatch 并执行一次 update论文用 total batch passes 描述 decay 被施加的次数；忽略尾 batch 时，\(N=BT/b\)。
raw weight-decay rate实际进入每步 update 的 decay rate记作 \(\lambda\) 或第 \(i\) 个 cycle 的 \(\lambda_i\)；它由 \(\lambda_{\mathrm{norm}}\) 和 budget 换算。
normalized weight decay把 budget 显式纳入 decay 换算论文提出 \(\lambda=\lambda_{\mathrm{norm}}\sqrt{b/(BT)}\) 以降低 optimal decay 对 batch passes 的依赖。
reparameterization换一组 parameters 描述或控制同一对象本课从直接调 raw \(\lambda\) 改为调 \(\lambda_{\mathrm{norm}}\)，再根据 \(N\) 换算回 \(\lambda\)；没有引入新的 decay mechanism。
cumulative multiplicative shrinkage同一个乘性因子重复作用后的总收缩纯 decay toy model 给出 \(\theta_N=(1-\lambda)^N\theta_0\)；它不包含 gradient 或 optimizer-state dynamics。
cosine annealing在一个 cycle 内按余弦曲线降低 schedule multiplier\(\eta_t\) 从 \(\eta_{\max}^{(i)}\) 平滑下降到 \(\eta_{\min}^{(i)}\)；不等于 restart 本身。
warm restart保留已有解并重启 schedule cycle重置 \(T_{cur}\) 并提高 \(\eta_t\)；不重新随机初始化 parameters，AdamWR 中也不清空 moments。
restart cycle / run两次 warm restarts 之间的一段训练第 \(i\) 个 cycle 的长度为 \(T_i\)。到达边界后进入下一 cycle。
schedule multiplier缩放 base update 的全局调度因子记作 \(\eta_t\)。AdamW 原论文 Algorithm 2 中，它同时缩放 adaptive step 与 decoupled decay。
anytime performance在任意中途预算点取得可用结果的能力论文引入 warm restarts 的目标；不同于只比较最终预算耗尽后的 final performance。
AdamWRAdamW 加 normalized decay 与 cosine warm restarts不是所有使用 cosine scheduler 的 AdamW run；必须同时满足论文中的组合路径。

Symbols

Symbol含义作用范围
\(B\)training points 总数Dataset-level count。
\(b\)batch size每次 minibatch update 使用的 examples 数。
\(T\)总 training epochs普通 normalized decay 的 budget；AdamWR 中换成当前 cycle 的 \(T_i\)。
\(N=BT/b\)batch-pass count忽略不完整 batch 时的 update 次数。
\(\propto\)proportional to（正比于）\(y\propto h(x)\) 表示 \(y=Ch(x)\)，其中 \(C\) 在当前比较范围内固定；本课中 \(\lambda\propto1/\sqrt N\) 的 \(C\) 是 \(\lambda_{\mathrm{norm}}\)。
\(\lambda_{\mathrm{norm}}\)normalized decay hyperparameter希望比 raw \(\lambda\) 更容易跨 budgets 复用；不是 universal constant。
\(\lambda_i\)第 \(i\) 个 cycle 的 raw decay rate\(\lambda_i=\lambda_{\mathrm{norm}}\sqrt{b/(BT_i)}\)。
\(\alpha\)base learning rate与 \(\eta_t\) 相乘形成当前 adaptive-step scale。
\(\eta_t\)schedule multiplier在 cycle 内随 \(T_{cur}/T_i\) 按 cosine 改变。
\(T_i\)第 \(i\) 个 restart cycle 的长度可通过 \(T_{i+1}=T_iT_{mult}\) 增长。
\(T_{cur}\)距上次 restart 已过的 epochs每个 batch 更新，因此可为非整数；restart 时归零。
\(T_{mult}\)cycle-length multiplier控制下一 cycle 相对当前 cycle 的长度。

不要混淆

不要混为一谈关键区别
normalized weight decay vs weight normalization前者是 decay hyperparameter scaling；后者通常指 parameter reparameterization，是另一类机制。
warm restart vs training from scratchWarm restart 保留已有 parameters；它重启 schedule，不重新初始化 model。
cosine annealing vs warm restartCosine annealing 描述 cycle 内下降；restart 描述 cycle boundary 上 multiplier 的回升。
base learning rate \(\alpha\) vs multiplier \(\eta_t\)前者是基础尺度，后者是随 schedule 改变的无量纲因子；当前尺度为 \(\eta_t\alpha\)。
square-root proposal vs theoretical law\(1/\sqrt{N}\) 是论文用有限实验提出的 normalization，不是严格保持累计 shrinkage 的定理。
\(1/N\) vs \(1/\sqrt N\)前者来自保持纯乘性 toy model 最终收缩近似不变；后者是 AdamW 论文用于提高 hyperparameter transferability 的经验规则。
reparameterization vs new mechanism\(\lambda_{\mathrm{norm}}\leftrightarrow\lambda\) 改变 hyperparameter 表示；optimizer 最终仍使用 raw \(\lambda\) 执行同一种 decay update。
cosine scheduler + AdamW vs AdamWR只有再按当前 cycle budget 使用 normalized decay，才对应论文定义的 AdamWR 组合。
