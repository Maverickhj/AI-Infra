Attention Glossary

术语以 English 为主；中文只用来锚定含义，而不替换术语本身。以后课程沿用这里的词，避免同一概念出现多个中文叫法。

适用：课程 0001 及后续 Transformer 课程 · Transformer 证据：Vaswani et al. (2017), §§3–5 · Adam 定义：Kingma & Ba (2014)

使用约定

English-first：首次出现写作 query（当前 token 的检索请求）；之后写 query。公式、张量名、代码符号与论文标题始终保持原样。

中文说明解释当前上下文的功能，不追求为每个 English term 制造固定译名。例如 key 在 attention 中更接近“供 query 匹配的索引”，而不仅是一个孤立的“键”。

Core terms

English term中文解释本课中的精确定义
Transformer由 attention 驱动的 sequence model原论文的 Encoder–Decoder architecture；不是所有现代 decoder-only LLM 的同义词。
Encoder处理完整 input sequence 的表示模块由 self-attention 与 FFN 组成；其输出是供 Decoder cross-attention 读取的 memory。
Decoder逐 token 生成 target sequence 的模块先经 masked self-attention 读取 target prefix，再经 cross-attention 读取 Encoder memory。
attention按相关性加权聚合信息一个 query 对多组 key–value pairs 计算权重，再对 values 加权求和。
self-attention序列内部的 attentionQ、K、V 来自同一序列的一层表示；Encoder 可见全序列，Decoder 另有 causal mask。
cross-attention / encoder-decoder attentionDecoder 从 Encoder memory 检索 source 信息Q 来自 Decoder；K、V 来自 Encoder output。它允许每个 Decoder position 读取所有 input positions。
query当前 token 的检索请求\(q_i\) 与每个 \(k_j\) 计算相容度，决定位置 \(i\) 想从哪里取信息。
key供 query 匹配的索引\(k_j\) 与 query 形成 attention score；它不是输出内容本身。
value被加权带回的信息\(v_j\) 按 attention weight 聚合，形成 attention output。
attention score / logitsoftmax 前的未归一化相容度\(S_{i,j}=q_i^\top k_j/\sqrt{d_k}+M_{i,j}\)。
attention weight归一化后的聚合权重\(A_{i,j}=\operatorname{softmax}(S_{i,:})_j\)；对固定 \(i\)，其各 \(j\) 项之和为 \(1\)。
representation subspace一组 projection 学到的子表示空间一个 head 通过其独立 \(W^{Q/K/V}\) 在该空间内计算 attention；它不是人工预先命名的语义槽位。
causal mask阻止未来信息流的约束在 softmax 前把 Decoder 中 \(j>i\) 的 score 置为 \(-\infty\)，使对应 weight 为 \(0\)。
autoregressive按生成历史逐 token 条件化预测位置 i 只使用已知的更早输出；这使 Decoder 推理仍有 token-level 串行依赖。
head一组独立的 Q/K/V 投影与 attentionmulti-head attention 并行计算多个 head，再拼接并投影；不同 head 没有必须互异的约束。
Position-wise Feed-Forward Network (FFN)逐位置前馈网络对每个 token representation 分别、相同地应用的两层 Linear 与中间 ReLU；它不直接混合 token positions。
ReLU activation非线性激活\(\max(0,x)\)。原论文将它置于 FFN 的两次 Linear 之间；没有它，两次 Linear 可合并为一次 Linear。
\(d_{\mathrm{ff}}\)FFN 的 inner-layer widthFFN 第一层的 hidden dimension；原论文 base configuration 中 \(d_{\mathrm{ff}}=2048\)，而 \(d_{\mathrm{model}}=512\)。
Residual Connection把 sub-layer 输入直接加到其输出\(x+\operatorname{Sublayer}(x)\)。两侧必须具有相同 shape，因此各 sub-layer 都输出 \(d_{\mathrm{model}}\)。
Layer Normalization (LayerNorm)逐 token 沿 features 归一化mean / variance 负责稳定每个 token 的统计尺度；learned gain 与 bias 再恢复每个 feature 可学习的尺度与偏移。它们不是 normalization 的逆运算。
Post-LNresidual addition 后归一化\(\operatorname{LayerNorm}(x+\operatorname{Sublayer}(x))\)；这是原始 Transformer 的排列。
Pre-LN进入 sub-layer 前归一化\(x+\operatorname{Sublayer}(\operatorname{LayerNorm}(x))\)；是后续常见变体，不是原论文 §3.1 的公式。
Positional Encoding (PE)注入 sequence position information原始 Transformer 把与 embedding 同为 \(d_{\mathrm{model}}\) 维的 sinusoidal PE 加到 input embedding；所有 heads 接收同一份相加后的 representation。
output projection / pre-softmax linear transformation把 Decoder representation 映射到 vocabulary logits将最后一维从 \(d_{\text{model}}\) 投影为 \(|\mathcal{V}|\)；每个 target position 独立得到一组 candidate-token logits。
vocabulary logitcandidate token 的未归一化分数output softmax 前的实数；不要与 attention 中的 query–key compatibility logit 混淆。
next-token probability下一个 token 的预测概率固定 batch item 与 target position，沿 vocabulary axis 对 logits 做 softmax 后得到。
weight tying多个用途共享同一组 parameters原始 Transformer 在 source embedding、target embedding 与 pre-softmax projection 之间共享同一个 weight matrix。
shifted targetDecoder input 与 prediction target 错开一位输入 \([\mathrm{BOS},y_1,\ldots,y_{T-1}]\)，对应预测 \([y_1,\ldots,y_T]\)；配合 causal mask 保持 autoregressive condition。
per-layer complexity单层理论计算量论文 Table 1 的 asymptotic arithmetic count；不直接等于具体硬件上的 latency、memory traffic 或 memory footprint。
minimum sequential operations受数据依赖约束的最少串行步骤衡量 layer computation 的可并行化边界；self-attention 为 \(O(1)\)，不表示 autoregressive token generation 可并行。
maximum path length任意 positions 间最长的 computational-graph 路径衡量 information / gradient 跨 positions 传播所需的最大 edge 数；不是 token distance 或 wall-clock time。
restricted self-attention只关注局部 neighborhood 的 self-attention论文 Table 1 中 complexity 为 \(O(rnd)\)、maximum path length 为 \(O(n/r)\)；它是作者提出的 future direction，不是原始 full-attention model 的配置。
optimizer step一次 parameter update 的编号Transformer schedule 中的 \(s\) / step_num；不是 token position、example count 或 epoch。
stochastic objective由随机 minibatch 或其他 noise source 形成的 step-level objective\(f_t(\theta)\) 随 step 的 sampled data / stochastic mechanism 改变，其 gradient \(g_t\) 因而是 stochastic estimate。
Adam first momentgradient 的 exponential moving average\(m_t=\beta_1m_{t-1}+(1-\beta_1)g_t\)；它保留 signed gradient direction history，原始 Transformer 使用 \(\beta_1=0.9\)。
Adam second raw momentsquared gradient 的 exponential moving average\(v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2\)；原始 Transformer 使用 \(\beta_2=0.98\)。
bias correction修正 zero initialization 造成的 early-step moment shrinkageAdam 使用 \(\widehat{m}_t=m_t/(1-\beta_1^t)\)、\(\widehat{v}_t=v_t/(1-\beta_2^t)\)。
adaptive moment estimation用 gradient moments 构造 per-coordinate update scaleglobal stepsize 仍存在；\(\sqrt{\widehat{v}_t}+\epsilon\) 使 denominator 随 parameter coordinate 的 gradient history 变化。
warmuptraining 初期逐步增大 learning rate原论文前 \(w=4000\) 个 optimizer steps 使用 linear branch，\(\alpha_s\propto s\)。
inverse-square-root decay按 step 平方根的倒数衰减warmup 后 \(\alpha_s\propto s^{-1/2}\)；它是 global schedule，不是 Adam second moment。

不要混淆

不要混为一谈关键区别
score / logit vs attention weight前者是 softmax 前、可为任意实数；后者是 softmax 后、非负且一行和为 1。
self-attention vs Decoder self-attention前者说明 Q/K/V 同源；后者额外施加 causal mask，不能看未来。
layer-level parallelism vs autoregressive generation训练时一层内可批量计算 \(QK^\top\)；生成下一个 token 仍须等待已有前缀。
LayerNorm vs BatchNorm本课中的 LayerNorm 对每个 token 沿 features 计算统计量；不依赖其他 batch examples 的统计量。
Post-LN vs Pre-LN两者都使用 residual 与 normalization，但归一化位置不同；原始 Transformer 是 Post-LN。
PE 的 pos / i / head indexpos 是 token position；i 是 sinusoidal frequency / feature pair index；二者都不是 head index。
Positional Encoding vs causal maskPE 提供 position signal；causal mask 约束 future target 的可见性。二者职责不同。
attention softmax vs output softmax前者沿 key positions 归一化并产生 aggregation weights；后者沿 vocabulary 归一化并产生 next-token probabilities。
weight sharing vs identical computationweight tying 表示多处引用同一 parameter matrix；embedding lookup、embedding scaling 与 output dot products 的计算仍不同。
asymptotic complexity vs runtimeBig-O 比较主导增长项；实际速度还取决于 constants、kernel efficiency、parallel hardware、memory traffic、batching 与 communication。
Adam adaptation vs LR scheduleAdam moments 调整每个 parameter coordinate 的 update；schedule 提供当前 optimizer step 的 global learning-rate scalar。
