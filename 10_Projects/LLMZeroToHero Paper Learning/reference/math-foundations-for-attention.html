四个主题

Linear Algebra 与 Symmetry

Vector、matrix、tensor shape、matrix multiplication、dot product、transpose、permutation matrix、equivariance 与 invariance。

Probability、Statistics 与 Estimation

Mean、variance、standardization、expectation、Bernoulli distribution、raw moment、centered variance 与 estimator bias。

Functions 与 Information Measures

Exponential、logarithm、proportionality、reparameterization、softmax、cross-entropy、entropy 与 KL divergence。

Sequences 与 Transforms

Geometric series、repeated multiplicative update、exponential approximation、EMA、rotation、power function 与 piecewise function。
