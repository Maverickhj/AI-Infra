Lesson 0007 · 约 12 分钟

Output Softmax 与 Weight Tying：hidden state 如何变成 next token？

Decoder stack 最终输出的仍是 \(d_{\text{model}}\)-dimensional representations，不是 token。模型还需要把每个 target position 的 representation 投影到整个 vocabulary，再经 softmax 得到 predicted next-token probabilities。

前置：课程 0006 · 数学：Vocabulary softmax · 术语：Output head · 主证据：Vaswani et al. (2017), §§3.1, 3.4

设计起点：representation 还不是 token

经过 masked self-attention、cross-attention 与 FFN 后，Decoder 对每个 target position 产生一个 contextual representation。它编码了当前 target prefix 与 source memory，但还没有回答“vocabulary 中哪个 token 应该排在下一位”。

Decoder output
每个 position 得到一个 \(d_{\text{model}}\)-dimensional hidden state。
↓
Output projection
为 vocabulary 中每个 candidate token 产生一个 logit。
↓
Vocabulary softmax
沿 vocabulary axis 把 logits 归一化为 next-token probability distribution。
↓
Consumer
training 用 target token 计算 loss；inference 从该 distribution 选择下一个 token。

从 \(d_{\text{model}}\) 投影到 vocabulary

设 batch size 为 \(B\)，target length 为 \(T\)，vocabulary 为 \(\mathcal{V}\)，其大小为 \(|\mathcal{V}|\)。Decoder stack 输出：

\[ Z\in\mathbb{R}^{B\times T\times d_{\text{model}}}. \]

令 output projection matrix 为 \(W_{\text{out}}\in\mathbb{R}^{|\mathcal{V}|\times d_{\text{model}}}\)。省略论文 §3.4 未说明的 output bias，则：

\[ \begin{aligned} L&=ZW_{\text{out}}^\top \in\mathbb{R}^{B\times T\times|\mathcal{V}|},\\ p_{b,t,v} &=\operatorname{softmax}_{\mathcal{V}}(L_{b,t,:})_v =\frac{\exp(L_{b,t,v})} {\sum_{u\in\mathcal{V}}\exp(L_{b,t,u})}. \end{aligned} \]

\(L_{b,t,v}\) 是 candidate token \(v\) 的 vocabulary logit；\(p_{b,t,v}\) 是模型分配给它的 probability。对固定的 batch item \(b\) 与 target position \(t\)，有：

\[ \sum_{v\in\mathcal{V}}p_{b,t,v}=1. \]
Shape 边界：projection 把最后一维从 \(d_{\text{model}}\) 变为 \(|\mathcal{V}|\)，不会把 sequence positions 合并。每个 target position 都得到自己的一份 vocabulary distribution。

两个 softmax，归一化轴完全不同

位置输入 shapesoftmax axis回答的问题
attention 内部\([B,h,T_q,T_k]\)key positions \(T_k\)当前 query 应从哪些 positions 取回信息？
Decoder output head\([B,T,|\mathcal{V}|]\)vocabulary \(|\mathcal{V}|\)当前位置的 next token 应是哪一个 vocabulary item？

二者都使用同一个 softmax 函数，但输入语义和 reduce axis 不同。Vocabulary softmax 不会产生 attention weights，attention softmax 也不会直接产生 token probabilities。

Shifted targets 如何维持 autoregressive condition？

对 target sequence \(y_1,\ldots,y_T\)，Decoder 的 input 与 prediction target 错开一个 position：

\[ \begin{aligned} \text{Decoder input} &=[\mathrm{BOS},y_1,\ldots,y_{T-1}],\\ \text{Prediction target} &=[y_1,y_2,\ldots,y_T]. \end{aligned} \]

因此 position \(t\) 应表示：

\[ p(y_t\mid y_{<t},x), \]

其中 \(x\) 是完整 source sequence。training 时，已知的 shifted targets 让所有 \(T\) 个 positions 可以一次进入矩阵计算；causal mask 保证 position \(t\) 的 hidden state 不能读取 \(y_t\) 或更晚的 targets。

inference 时没有完整 target 可供 shift。模型先产生一个 next-token distribution，选择一个 token 并追加到 prefix，然后再次运行 Decoder。因此 layer 内可以并行，不等于 autoregressive generation 的 token steps 可以并行。

Weight Tying：同一个 matrix 承担三种角色

令 learned token embedding matrix 为：

\[ \mathcal{E} \in\mathbb{R}^{|\mathcal{V}|\times d_{\text{model}}}. \]

原始 Transformer 在两个 embedding layers 与 pre-softmax linear transformation 之间共享同一个 weight matrix。令 \(W_{\mathrm{src}}\)、\(W_{\mathrm{tgt}}\) 与 \(W_{\mathrm{out}}\) 分别表示这三处的 matrix；用上述 row-major 记法：

\[ W_{\mathrm{src}} =W_{\mathrm{tgt}} =W_{\text{out}} =\mathcal{E}. \]
使用位置如何使用 \(\mathcal{E}\)输出
source embedding按 source token id 查一行\(d_{\text{model}}\)-dimensional vector
target embedding按 target token id 查一行\(d_{\text{model}}\)-dimensional vector
output projectionhidden state 与所有 rows 做 dot products\(|\mathcal{V}|\) 个 logits

在 embedding 用法中，论文把 lookup vector 乘以 \(\sqrt{d_{\text{model}}}\)；pre-softmax output projection 不做这项 embedding scaling。共享的是 learned parameters，不是三处完全相同的 computation。

适用条件：三向 weight tying 要求 source、target 与 output 使用兼容的 vocabulary / token-id mapping，且 embedding width 与 Decoder output width 都是 \(d_{\text{model}}\)。若 source 与 target 使用不兼容的 vocabularies，就不能直接共享同一张完整矩阵。

Weight tying 改变了什么，没改变什么？

下面是由矩阵形状直接得到的 parameter-count 推论，不是论文 §3.4 给出的效果证明。若三处各有独立 matrix，忽略 biases 时参数量为：

\[ 3|\mathcal{V}|d_{\text{model}}. \]

三向共享后只需：

\[ |\mathcal{V}|d_{\text{model}}, \]

因此减少 \(2|\mathcal{V}|d_{\text{model}}\) 个 parameters。共享还使 token 的 input embedding 与 output candidate vector 使用同一组 learned rows，但它不要求 Decoder hidden state 等于某个 embedding，也不保证某个 token 一定获得高 probability；contextual Decoder computation 仍决定最终 dot products。
