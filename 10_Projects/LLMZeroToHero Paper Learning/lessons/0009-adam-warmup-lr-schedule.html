Adam、Warmup 与 Learning-Rate Schedule：参数如何开始移动？

Transformer architecture 定义了 forward computation，但不会自动给出稳定、有效的 parameter updates。原论文使用 Adam 处理 gradient history，再用一个依赖 \(d_{\text{model}}\) 与 optimizer step 的 global learning-rate schedule 控制更新尺度。

前置：课程 0008 · 数学：Adam 与 schedule 数学起步 · 术语：Optimization terms · 主证据：Vaswani et al. (2017), §§5.2–5.3 · Adam 定义：Kingma & Ba (2014)

先分开两个控制层

机制输入控制对象本课中的角色
Adam moment adaptation当前与历史 gradients每个 parameter coordinate 的 normalized update用 first / second moment estimates 调整不同 coordinates 的方向与尺度。
Transformer LR schedule\(d_{\text{model}}\)、optimizer step \(s\)、warmup steps \(w\)全局 learning-rate scalar \(\alpha_s\)先 linear warmup，再 inverse-square-root decay。

Adam 并不取代 schedule，schedule 也不取代 Adam。一次 parameter update 同时使用 Adam 的 per-coordinate normalization 与当前 step 的 global learning rate。

Adam 的最小数学：\(\beta_1\)、\(\beta_2\)、\(\epsilon\) 在做什么？

令 \(\theta_{s-1}\) 为 optimizer step \(s\) 开始前的 parameters，\(g_s\) 为当前 stochastic gradient；update 后得到 \(\theta_s\)。Adam 维护：

\[ \begin{aligned} m_s &=\beta_1m_{s-1}+(1-\beta_1)g_s,\\ v_s &=\beta_2v_{s-1}+(1-\beta_2)g_s^2. \end{aligned} \]

所有 vector operations 都按 coordinate 执行，\(g_s^2\) 是 element-wise square。\(m_s\) 估计 gradient 的 first moment，\(v_s\) 估计 squared gradient 的 second raw moment。因为二者从 zero 初始化，Adam 还使用 bias correction：

\[ \widehat{m}_s =\frac{m_s}{1-\beta_1^s}, \qquad \widehat{v}_s =\frac{v_s}{1-\beta_2^s}. \]

给定当前 global learning rate \(\alpha_s\)，update 为：

\[ \theta_s =\theta_{s-1} -\alpha_s \frac{\widehat{m}_s} {\sqrt{\widehat{v}_s}+\epsilon}. \]
Hyperparameter原始 Transformer精确作用
\(\beta_1\)\(0.9\)first-moment exponential moving average 的 decay rate。
\(\beta_2\)\(0.98\)second-raw-moment exponential moving average 的 decay rate。
\(\epsilon\)\(10^{-9}\)加入 denominator，避免除零并影响极小 \(v_s\) 下的数值尺度。
证据边界：Transformer 论文报告了这组配置，但没有在 §5.3 给出选择 \(\beta_2=0.98\)、\(\epsilon=10^{-9}\) 的消融或因果证明。它们也不同于 Adam 原论文列出的通用 default \(\beta_2=0.999\)、\(\epsilon=10^{-8}\)。

原始 Transformer 的 learning-rate 公式

令 \(s\geq1\) 为 step_num，\(w\) 为 warmup_steps。论文定义：

\[ \alpha_s =d_{\text{model}}^{-1/2} \min\left( s^{-1/2}, s\,w^{-3/2} \right), \qquad w=4000. \]

这里的 \(\min\) 不是装饰。两条 branch 在 \(s=w\) 时相交：

\[ \begin{aligned} s^{-1/2} &=s\,w^{-3/2}\\ s^{3/2} &=w^{3/2}\\ s&=w. \end{aligned} \]

因此 schedule 可以等价写成：

\[ \alpha_s =d_{\text{model}}^{-1/2} \begin{cases} s\,w^{-3/2}, & 1\leq s\leq w,\\ s^{-1/2}, & s\geq w. \end{cases} \]

两段 schedule 的 causal interpretation

Warmup phase
当 \(1\leq s\leq w\) 时，\(\alpha_s\propto s\)：learning rate 从较小值 linear increase。
↓
Peak
在 \(s=w\) 时两条 branch 相等，learning rate 达到最大值。
↓
Decay phase
当 \(s\geq w\) 时，\(\alpha_s\propto s^{-1/2}\)：learning rate 按 inverse square root 缓慢下降。

peak learning rate 由公式直接得到：

\[ \alpha_{\max} =\alpha_w =\frac{1}{\sqrt{d_{\text{model}}w}}. \]

对 base model 的 \(d_{\text{model}}=512\)、\(w=4000\)：

\[ \alpha_{\max} =\frac{1}{\sqrt{512\cdot4000}} \approx6.99\times10^{-4}. \]
\(d_{\text{model}}\) scaling：在相同 \(s,w\) 下，width 更大的 model 得到更小的 global learning-rate scalar。论文采用了这一公式；不能据此推出它对任意 architecture、batch size 或 optimizer configuration 都是最优 scaling law。

step_num 不是 token count，也不是 epoch

schedule 中的 \(s\) 是 optimizer update count。一个 step 可以消费一个 batch，而 batch 中包含多少 examples、source tokens 或 target tokens，取决于 batching 与 gradient accumulation configuration。

复现实验边界：只复制 \(w=4000\) 而改变 global batch、tokens per update、gradient accumulation 或 data distribution，会改变 warmup 期间实际见过的 token 数。因此“相同 warmup steps”不等于“相同 optimization exposure”。
