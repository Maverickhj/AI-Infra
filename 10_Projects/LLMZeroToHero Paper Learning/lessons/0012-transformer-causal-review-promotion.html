Attention Is All You Need · Lesson 0012 · Final Review · 约 25 分钟

从机制拼图回到整篇论文的因果链

前十一课分别解释了 Transformer 的组件。最终课不再增加新组件，而是检查这些机制是否共同形成一个闭环：论文替换了什么约束、怎样补回被移除结构原本提供的能力、如何把 architecture 训练成 system、证据支持到哪里，以及哪些结论已经成熟到可以离开项目笔记。

前置：Lesson 0011 · 总索引：Attention 因果链 · 主证据：Vaswani et al., Attention Is All You Need

一句话 thesis

原论文的核心不是“发明 attention”——Encoder–Decoder models 之前已经使用 attention。它提出的是：在 sequence transduction 的 Encoder 与 Decoder 中，能否用 attention-based layers 替代 recurrent 与 convolutional sequence-processing layers，同时保持 translation quality，并显著提高 training parallelizability。

版本边界：这篇论文研究的是原始 Encoder–Decoder Transformer，不是现代 decoder-only LLM 的完整设计说明，也没有讨论 KV cache、FlashAttention、RoPE、Mixture-of-Experts 或 distributed training。

总因果链：替换一个约束，会连续产生哪些新问题？

Existing constraint
RNN 的 \(h_t=f(h_{t-1},x_t)\) 在同一 sequence 内形成 recurrence dependency；convolution 需要通过固定 receptive field 或多层路径传播远距离信息。
↓
Core replacement
Self-attention 用 \(QK^\top\) 一次构造 query–key pairwise relations，使同一 layer 内各 positions 可以批量计算，并把任意两个 positions 的 maximum path length 降为 \(O(1)\)。
↓
New capacity problem
Single-head weighted average 会把多种 relation 压进同一 distribution；Multi-Head Attention 用多组 learned projections 保留多种可学习的 matching / aggregation patterns。
↓
New structure problem
Attention 负责跨 positions 通信，但还需要 position-wise non-linearity、stackable interfaces 与 sequence-order signal。
↓
Architectural closure
FFN 提供逐 position 非线性容量；Residual Connection 与统一 \(d_{\mathrm{model}}\) interface 支持堆叠；LayerNorm 稳定 feature statistics；Positional Encoding 补回 order information。
↓
Task closure
Encoder self-attention 构造 source memory；Decoder masked self-attention 表示 target prefix；cross-attention 把 current target-side need 对齐到 source memory；output projection 与 softmax 产生 next-token distribution。
↓
Training closure
Adam 与 warmup schedule 控制 parameter update；length-aware token batching 控制 variable-length workload；dropout 与 label smoothing regularize training。
↓
Evidence
Table 1 给出 theoretical complexity/path comparison；Table 2 给出完整 translation system 的 test results；Table 3 给出特定 dev setup 下的 model variations。

论文 causal chain 思维导图

从中心的 core replacement 向外读：它先回应已有瓶颈，再要求 architecture 与 training 分别闭环；论文证据只能支持特定边界内的结论，并把未解决的问题留给后续工作。

Existing constraints / bottlenecks

  • RNN：sequence 内存在 recurrence dependency。
  • Convolution：远距离信息需要固定 receptive field 或多层路径。

Architecture closure

  • MHA 分离多组 matching / aggregation patterns。
  • FFN、Residual、Post-LN 与 PE 补齐容量、堆叠接口与 order signal。
  • Encoder、masked Decoder 与 cross-attention 闭合 sequence transduction。

Training closure

  • Adam 与 warmup 控制 parameter update。
  • Token batching 控制 variable-length workload。
  • Dropout 与 label smoothing 提供 regularization。

Costs / boundaries

  • Full self-attention 的 per-layer complexity 为 \(O(n^2d)\)。
  • Autoregressive inference 仍受 next-token dependency 限制。
  • 结论范围是原始 Encoder–Decoder、Post-LN Transformer。

Information-flow closure：三种 attention 为什么不能混用？

LocationQ sourceK/V sourceInformation question
Encoder self-attentionEncoder statesEncoder states当前 source position 应从完整 source sequence 读取什么？
Decoder masked self-attentionDecoder statesDecoder states当前 target position 应从 causal target prefix 读取什么？
Cross-attentionDecoder statesEncoder memory当前 target-side need 应从 source memory 读取什么？

这对应 sequence-to-sequence factorization：

\[ p(y\mid x) =\prod_{t=1}^{m} p(y_t\mid y_{<t},x). \]

Masked self-attention 提供 \(y_{<t}\) 条件，cross-attention 提供 \(x\) 条件。Cross-attention 本身不需要 target causal mask，因为 future target states 没有作为其 K/V；但 source padding positions 仍可能需要 padding mask。

Final gap check 1：Cross-Attention

Learning Record 0003 仍把这一点标记为“部分建立”。完成本课时应能从 conditional factorization 推出，而不是只记住 Q/K/V 排列：

  • Decoder query 表示基于 causal prefix 形成的 current target-side need。
  • Encoder keys / values 表示 generation 前已经构造好的 source memory。
  • Attention output 更新 query 所在一侧，因此由 Decoder 提 Q，正好得到 source-conditioned target representation。
  • Source length \(n\) 与 target length \(m\) 没有固定大小关系；training 可同时处理 \(m\) 个 target queries，incremental inference 常只添加一个新 query。

Final gap check 2：Residual 与 LayerNorm

Learning Record 0005 仍需要钉牢 normalization axis 与 Post-LN boundary。对 \(X\in\mathbb{R}^{B\times N\times d_{\mathrm{model}}}\)，原论文 block 可写为：

\[ y_{b,t,:} =\operatorname{LayerNorm} \left( x_{b,t,:} +\operatorname{Dropout}(F(x)_{b,t,:}) \right). \]

LayerNorm 固定 batch item \(b\) 与 token position \(t\)，沿 \(d_{\mathrm{model}}\) features 计算 statistics；同一 module 的 \(\gamma,\beta\in\mathbb{R}^{d_{\mathrm{model}}}\) 在 batch items 与 token positions 间共享。若 \(F(x)=0\)，整个 Post-LN output 是 \(\operatorname{LayerNorm}(x)\)，不是严格的 \(x\)。

Statement是否成立Scope

Transformer 移除的是 layer 内 recurrence，不是 autoregressive factorization。

Paper-level summary template

最终不应按“论文有几个 section”来总结，而应回答六个问题：

  1. Previous constraint：被替换方案留下了什么 bottleneck？
  2. Core change：论文改变了哪条 data dependency 或 computation graph？
  3. Architectural closure：为弥补替换产生的新缺口，又加入了哪些 mechanisms？
  4. Training closure：哪些 recipe 让 architecture 成为可训练 system？
  5. Evidence：理论比较、benchmark 与 ablation 分别支持什么？
  6. Boundary / successor questions：论文没有解决什么，哪些问题留给后续工作？
