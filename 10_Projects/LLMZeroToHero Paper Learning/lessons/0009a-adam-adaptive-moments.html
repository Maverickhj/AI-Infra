Adam：从 Noisy SGD 到 Adaptive Moments

Transformer 论文告诉我们它“使用 Adam”，但没有展开 Adam 为什么维护两组 moment estimates。本课回到 Adam 自己的问题设定：面对 minibatch noise、high-dimensional parameters 与不同 coordinate 的 gradient scales，如何只用 first-order gradients 构造 adaptive updates？

前置：课程 0009 · 数学：Adam 数学起步 · 术语：Adam terms · 主证据：Kingma & Ba, Adam: A Method for Stochastic Optimization, §§1–2, Algorithm 1

设计起点：gradient 为什么是 stochastic 的？

设完整 training objective 是许多 data examples 的 aggregate。实际 training 通常不会在每次 update 前遍历全部数据，而是从 minibatch 构造 stochastic objective \(f_t(\theta)\)，并计算：

\[ g_t =\nabla_\theta f_t(\theta_{t-1}). \]

因为 minibatch composition 会变化，连续 steps 的 \(g_t\) 可能在方向与 magnitude 上波动。Dropout 等 stochastic mechanisms 也可能增加这种 noise。Adam 论文特别关注 large parameter spaces，以及 noisy、sparse 或 non-stationary gradient settings。

不要制造错误因果：这不表示 SGD 无法处理 stochastic gradients。Adam 的设计目标是在只使用 first-order gradients 的前提下，用历史 moments 为不同 parameter coordinates 构造 adaptive learning rates。

SGD baseline 留下了什么自由度？

最小 SGD update 可以写成：

\[ \theta_t =\theta_{t-1} -\alpha g_t. \]

同一个 global stepsize \(\alpha\) 乘到所有 coordinates；当前 minibatch gradient 直接决定这一步的方向和相对 magnitude。这个 baseline 没有在 optimizer state 中显式保存“近期方向是否一致”或“某个 coordinate 的 gradient 通常有多大”。

在 Adam 提出之前，momentum、AdaGrad 与 RMSProp 已经分别处理了这些问题的一部分。Adam 论文将自己的设计描述为结合 AdaGrad 对 sparse gradients 的适应能力与 RMSProp 对 online / non-stationary settings 的适应能力。

First moment：平滑近期 gradient direction

Adam 为每个 parameter coordinate 维护 gradient 的 exponential moving average：

\[ m_t =\beta_1m_{t-1} +(1-\beta_1)g_t, \qquad m_0=0. \]

把 recurrence 展开：

\[ m_t =(1-\beta_1) \sum_{i=1}^{t} \beta_1^{\,t-i}g_i. \]

越近的 gradient 权重越大，越早的 gradient 按 \(\beta_1^{t-i}\) 衰减。若一个 coordinate 的 gradients 长期同向，\(m_t\) 会保留该方向；若频繁正负翻转，moving average 会发生抵消。

\(\beta_1\) 越接近 \(1\)，历史衰减越慢；越接近 \(0\)，\(m_t\) 越接近当前 gradient。它控制 history weighting，不是 learning rate 本身。

Second raw moment：估计近期 squared magnitude

Adam 同时维护：

\[ v_t =\beta_2v_{t-1} +(1-\beta_2)g_t^2, \qquad v_0=0, \]

其中 \(g_t^2=g_t\odot g_t\) 是 element-wise square。展开后：

\[ v_t =(1-\beta_2) \sum_{i=1}^{t} \beta_2^{\,t-i}g_i^2. \]
术语边界：\(v_t\) 估计的是 second raw moment，即 \(\mathbb{E}[g^2]\)，不是 centered variance。两者关系为 \(\operatorname{Var}(g)=\mathbb{E}[g^2]-\mathbb{E}[g]^2\)。

为什么需要专门区分 raw moment 与 variance？

比较的目的不是暗示两种计算应该相同，而是防止把 \(v_t\) 错读成“gradient 的波动程度”。考虑两个 idealized long-run gradient distributions：

Gradient pattern\(\mathbb{E}[g]\)\(\mathbb{E}[g^2]\)\(\operatorname{Var}(g)\)
\(g=10\) 恒定不变\(10\)\(100\)\(0\)
\(g\in\{-10,+10\}\)，等概率\(0\)\(100\)\(100\)

第一种 gradient 完全不波动，所以 centered variance 为 \(0\)；但它的 magnitude 始终为 \(10\)，因此 second raw moment 是 \(100\)。两种 pattern 的 \(\mathbb{E}[g^2]\) 相同，所以 \(v_t\) 会为它们记录相近的 squared scale；\(m_t\) 则区分“长期稳定同向”与“正负方向相互抵消”。

为什么这个区别影响 Adam：如果误以为 \(v_t\) 是 variance，就会错误预测“恒定大 gradient 的 denominator 接近 \(0\)”。实际上 Adam 的 denominator 会看到其非零 squared magnitude。Adam 用 \(m_t\) 表示 signed direction consistency，用 \(v_t\) 表示 total squared scale。

\(\beta_2\) 控制 squared-gradient history 的衰减。某个 coordinate 近期 gradient magnitude 经常较大时，对应 \(v_t\) 通常也较大。

Algorithm 1：两组 moments 如何合成一次 update？

因为 \(m_0=v_0=0\)，Adam 先构造 bias-corrected estimates：

\[ \widehat{m}_t =\frac{m_t}{1-\beta_1^t}, \qquad \widehat{v}_t =\frac{v_t}{1-\beta_2^t}. \]

然后按 coordinate 更新：

\[ \theta_t =\theta_{t-1} -\alpha \frac{\widehat{m}_t} {\sqrt{\widehat{v}_t}+\epsilon}. \]

由 stochastic objective 得到 \(g_t\)。
↓
Direction estimate
\(m_t\) 聚合近期 signed gradients。
↓
Scale estimate
\(v_t\) 聚合近期 squared gradients。
↓
Normalized update
用 \(\widehat{m}_t/(\sqrt{\widehat{v}_t}+\epsilon)\) 构造 per-coordinate update，再乘 global stepsize \(\alpha\)。

Bias correction 为什么恰好除以 \(1-\beta^t\)，留到 Lesson 0009B 从展开式推导；本课先掌握 producer-to-consumer data flow。

\(t=0\) 只做初始化：第一次 update 从 \(t=1\) 开始

Adam Algorithm 1 首先建立 initial state：

\[ \theta_0=\text{initial parameters}, \qquad m_0=0, \qquad v_0=0, \qquad t=0. \]

此时还没有根据 data 计算 gradient，因此不执行 parameter update。进入 optimization loop 后，算法先令 \(t\leftarrow t+1\)，再在 \(\theta_0\) 上计算第一次 stochastic gradient：

\[ g_1 =\nabla_\theta f_1(\theta_0). \]

代入 zero-initialized moment states：

\[ \begin{aligned} m_1 &=\beta_1m_0+(1-\beta_1)g_1 =(1-\beta_1)g_1,\\ v_1 &=\beta_2v_0+(1-\beta_2)g_1^2 =(1-\beta_2)g_1^2. \end{aligned} \]

第一次 bias correction 会恰好约去这两个 initialization factors：

\[ \begin{aligned} \widehat{m}_1 &=\frac{m_1}{1-\beta_1} =g_1,\\ \widehat{v}_1 &=\frac{v_1}{1-\beta_2} =g_1^2. \end{aligned} \]

所以第一次 parameter update 为：

\[ \theta_1 =\theta_0 -\alpha \frac{g_1} {\sqrt{g_1^2}+\epsilon}. \]

对 scalar coordinate \(j\)，有 \(\sqrt{g_{1,j}^2}=|g_{1,j}|\)。当 \(g_{1,j}\neq0\) 且 \(\epsilon\) 相对很小时：

\[ \theta_{1,j}-\theta_{0,j} \approx -\alpha\,\operatorname{sign}(g_{1,j}). \]

因此第一次 Adam update 的 normalized magnitude 通常接近 global stepsize \(\alpha\)，方向由该 coordinate 的 gradient sign 决定；若 \(g_{1,j}=0\)，其 update 为 \(0\)。若外部还使用 Transformer learning-rate schedule，这里的 \(\alpha\) 应替换为 first-step global learning rate \(\alpha_1\)。

Indexing boundary：算法不会在 \(t=0\) 计算 \(\widehat{m}_0=m_0/(1-\beta_1^0)\) 或 \(\widehat{v}_0=v_0/(1-\beta_2^0)\)，因为 denominator 为 \(0\)。准确顺序是 \(t=0\rightarrow t=1\rightarrow g_1\rightarrow m_1,v_1\rightarrow\widehat{m}_1,\widehat{v}_1\rightarrow\theta_1\)。

一个 two-coordinate 例子

忽略 \(\epsilon\)，假设 bias correction 后两个 coordinates 的 first moment 相同，但 second raw moment 不同：

\[ \begin{aligned} \widehat{m}_{t,a} &=0.1, &\widehat{v}_{t,a} &=0.01,\\ \widehat{m}_{t,b} &=0.1, &\widehat{v}_{t,b} &=1. \end{aligned} \]

则 normalized update factors 为：

\[ \begin{aligned} \frac{\widehat{m}_{t,a}} {\sqrt{\widehat{v}_{t,a}}} &=\frac{0.1}{0.1}=1,\\ \frac{\widehat{m}_{t,b}} {\sqrt{\widehat{v}_{t,b}}} &=\frac{0.1}{1}=0.1. \end{aligned} \]

即使两者的 smoothed direction 相同，recent squared-gradient scale 更大的 coordinate \(b\) 得到更小的 normalized factor。这里展示的是公式结果，不表示 Adam 永远会让“大 gradient coordinate”更新更慢；实际结果同时取决于 \(\widehat{m}_t\)、\(\widehat{v}_t\)、\(\epsilon\) 与 \(\alpha\)。

为什么称为 adaptive learning rates？

把 update 的第 \(j\) 个 coordinate 写开：

\[ \theta_{t,j} =\theta_{t-1,j} -\underbrace{ \frac{\alpha} {\sqrt{\widehat{v}_{t,j}}+\epsilon} }_{\text{coordinate-dependent scale}} \widehat{m}_{t,j}. \]

虽然 \(\alpha\) 是 global stepsize，但 denominator 随 coordinate \(j\) 的 squared-gradient history 改变，因此每个 coordinate 获得不同的 effective scale。这就是 adaptive moment estimation 中 “adaptive” 的直接数学位置。

当 \(\epsilon=0\) 且 gradient 被 positive constant \(c\) 按 coordinate rescale 时：

\[ \frac{c\widehat{m}_t} {\sqrt{c^2\widehat{v}_t}} = \frac{\widehat{m}_t} {\sqrt{\widehat{v}_t}}. \]

这说明 normalized factor 对这种 gradient rescaling 不变。实际有 \(\epsilon>0\) 时，在 denominator 与 \(\epsilon\) 同量级的区域，这个等式不再严格成立。

State 与 memory boundary

若 parameter vector 有 \(|\theta|\) 个 elements，Adam 至少维护与 parameters 同 shape 的 \(m_t\) 与 \(v_t\)：

\[ M_{\text{moment state}} =2|\theta|b, \]

其中 \(b\) 是每个 moment element 的 byte width。因此 moment state 是 \(O(|\theta|)\) memory，而不是 zero overhead。Adam 论文所说的 “little memory requirements” 应理解为其 first-order algorithm context；mixed precision master weights、gradient buffers、distributed sharding 与 framework-specific states 不在原论文这句话的计数中。

这一课暂时不能推出什么？

边界清单：Algorithm 1 不表示 Adam 不再需要 global learning rate；\(v_t\) 不是 Hessian 或完整 cross-coordinate covariance；一个 two-coordinate 例子不是 convergence proof；原论文的 theoretical claim 有特定 assumptions，其历史与后续修正留到 Lesson 0009C。
