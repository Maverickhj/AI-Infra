Positional Encoding：移除 recurrence 后，顺序从哪里来？

Self-attention 可以一次连接任意 positions，但其 Q/K/V 计算本身不会自动知道哪个 token 在前、哪个在后。原始 Transformer 因此把 Positional Encoding（位置编码）加到 token embeddings 上，在不恢复串行 recurrence 的前提下注入 sequence order。

前置：课程 0005 · 数学：Permutation matrix、equivariance、trigonometric transform · 术语：Attention Glossary · 主证据：Vaswani et al. (2017), §§3.4–3.5, 6.2

设计起点：并行化也移除了顺序结构

RNN 的 state 按 \(h_t=f(h_{t-1},x_t)\) 顺序传递，convolution 也通过固定的邻域结构携带 position relationship。Transformer 移除了两者后，attention 可以并行处理全部 tokens，但 token representation 中必须另有信号说明 sequence position。

已有机制
self-attention 根据 token representations 产生 Q/K/V，并按 content compatibility 汇聚信息。
↓
缺失信息
若 representations 只含 token identity / content，相同内容出现在不同 positions 时，没有显式 position coordinate。
↓
补充机制
在 Encoder 与 Decoder stack 的底部，把 Positional Encoding 加到 token embedding。
↓
保留收益
positions 仍可并行计算，同时 Q/K/V projections 能读取 content 与 position 的组合信号。

从 attention 公式看 permutation equivariance

下面把 permutation matrix（置换矩阵）与 equivariance（等变性）实例化到 self-attention；这是由公式得到的数学推论，不是论文中的逐字表述。设 \(P\) 重新排列 sequence rows。若没有 positional signal 与 mask：

\[ \begin{aligned} Q'&=(PH)W_Q=PQ,\\ K'&=(PH)W_K=PK,\\ V'&=(PH)W_V=PV,\\ \operatorname{Attention}(PH) &=P\operatorname{Attention}(H). \end{aligned} \]

也就是说，把 input rows 重新排序，attention outputs 只会跟着以相同方式重新排序；attention 本身没有获得“原来的第几个 position”这一额外信息。这称为 permutation equivariance（置换等变性）。

边界：Decoder causal mask 本身规定了哪些 earlier positions 可见，因此 masked attention 不满足上面的无 mask 推导。但 mask 的职责是限制 information flow；原论文仍在 Encoder 与 Decoder 两侧都加入 Positional Encoding，以显式提供 relative / absolute position information。

原始 Transformer 如何注入 position？

论文令 token embedding 与 Positional Encoding 都具有 \(d_{\text{model}}\) 维，并逐元素相加：

\[ X_{\mathrm{pos}} =\sqrt{d_{\text{model}}}\, E(\mathrm{token}_{\mathrm{pos}}) +PE_{\mathrm{pos}}, \qquad X,PE\in\mathbb{R}^{N\times d_{\text{model}}}. \]

embedding scaling 来自论文 §3.4；training 时还会对 embedding 与 PE 的和应用 dropout。这里选择 addition 而非 concatenation，使输出 width 仍为 \(d_{\text{model}}\)，可直接进入后续 Transformer stack。

相加不表示 content 与 position 永远无法区分。后续 learned projections 可以从组合 representation 中学习有用的 content–position interactions。

Sinusoidal Positional Encoding 的原始公式

原论文对每个 token position \(\mathrm{pos}\) 和每组 feature pair \(i\) 定义：

\[ \begin{aligned} PE_{(\mathrm{pos},2i)} &=\sin\!\left( \frac{\mathrm{pos}} {10000^{2i/d_{\text{model}}}} \right),\\ PE_{(\mathrm{pos},2i+1)} &=\cos\!\left( \frac{\mathrm{pos}} {10000^{2i/d_{\text{model}}}} \right). \end{aligned} \]
符号精确含义不要混淆
\(\mathrm{pos}\)sequence 中的 token position。不是 feature index，也不是 head index。
\(i\)sin/cos frequency pair 的索引；对应 feature coordinates \(2i\) 与 \(2i+1\)。不是 attention 中 query position \(i\) 的固定写法，也不分配给某个 head。
\(d_{\text{model}}\)完整 token representation width。不是单个 \(d_{\text{head}}\)。

所有 heads 接收同一份 \(X=E+PE\)，然后分别用自己的 \(W_r^Q,W_r^K,W_r^V\) 从完整 \(d_{\text{model}}\) representation 投影。不存在“不同 head 分配不同 PE dimensions”的原始模型约束。

为什么一对 sine / cosine 能表达固定 offset？

令一组 frequency 为 \(\omega_i=10000^{-2i/d_{\text{model}}}\)，并把对应 feature pair 写成：

\[ p_i(\mathrm{pos})= \begin{bmatrix} \sin(\omega_i\mathrm{pos})\\ \cos(\omega_i\mathrm{pos}) \end{bmatrix}. \]

对任意固定 offset \(k\)，三角加法公式给出：

\[ p_i(\mathrm{pos}+k) = \begin{bmatrix} \cos(\omega_i k) & \sin(\omega_i k)\\ -\sin(\omega_i k) & \cos(\omega_i k) \end{bmatrix} p_i(\mathrm{pos}). \]

因此，对于固定 \(k\)，从 \(PE_{\mathrm{pos}}\) 到 \(PE_{\mathrm{pos}+k}\) 存在一个只依赖 offset 的 linear transform。论文将这作为选择 sinusoidal functions 的动机：作者 hypothesized（假设）这会让模型更容易按 relative positions 做 attention；它不是“模型必然精确恢复任意距离”的证明。

Fixed sinusoidal 与 learned positional embeddings

方案参数与长度论文证据
sinusoidal PE由公式生成，无 learned position table；可计算训练长度之外的 positions。原始 base model 采用。
learned positional embeddings每个训练范围内的 position 学一个 vector。论文 ablation 中与 sinusoidal 结果近似。

作者选择 sinusoidal version，是因为它可能 extrapolate 到 training 中未见过的更长 sequence lengths。这里必须保留 “may”：公式允许计算更长 positions，不等于模型质量被保证能外推。
