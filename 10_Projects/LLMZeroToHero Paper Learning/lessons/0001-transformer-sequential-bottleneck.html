从串行瓶颈到 Scaled Dot-Product Attention

这不是“Transformer 有 Q、K、V”的背诵课。完成后，你应能从 RNN 的计算依赖出发，推导 attention 必须计算的张量，并准确说出它换来的好处和代价。

任务：LLMZeroToHero 论文因果学习 · 主证据：Vaswani et al. (2017), §§1, 3.2, 4

术语约定：English-first；首次出现的中文解释见 Attention Glossary。

开始前（可选，约 8 分钟）：若你对矩阵乘法、点积、softmax 或 mask 的“形状和语义”还不稳，先看 Attention 数学起步。它只覆盖本课会用到的数学，不要求先学完线性代数。

先抓住要被替换的约束

对长度为 \(n\) 的序列，典型 RNN 递推为 \(h_t=f(h_{t-1},x_t)\)。这不是“实现不够快”的问题：要得到 \(h_t\)，先必须得到 \(h_{t-1}\)。因此，同一训练样本内至少有 \(O(n)\) 个串行步骤。

论文的切入点：如果每个位置能在同一层直接读取其他位置，就能移除这条按 token 排队的计算依赖。Transformer 选择的答案是 self-attention，而不是更深的卷积或更快的 RNN。

原论文比较的是三个量：每层复杂度、最少串行操作数、远距离依赖的最大路径长度。它给出完整 self-attention 的 \(O(n^2d)\)、\(O(1)\)、\(O(1)\)；RNN 为 \(O(nd^2)\)、\(O(n)\)、\(O(n)\)。

边界：“\(O(1)\) 串行操作”不等于 decoder 可以一次生成所有未来 token，也不等于 attention 在长序列下没有 \(n^2\) 的内存和计算代价。两件事分别属于自回归依赖和 layer 内的 attention 代价。

把“读取其他位置”写成一个矩阵计算

设一层输入为 \(H\in\mathbb{R}^{n\times d_{\mathrm{model}}}\)。每个 token 同时投影出 query（当前 token 的检索请求）、key（供 query 匹配的索引）和 value（被加权带回的信息）：

\[ \begin{aligned} Q=HW_Q&\in\mathbb{R}^{n\times d_k},\\ K=HW_K&\in\mathbb{R}^{n\times d_k},\\ V=HW_V&\in\mathbb{R}^{n\times d_v}. \end{aligned} \]

第 \(i\) 个 query 与所有 key 的点积组成 attention score / logit（softmax 前的未归一化相容度）行；把全部 token 堆叠就是 \(QK^\top\in\mathbb{R}^{n\times n}\)。对每行归一化后，再加权 values：

\[ \begin{aligned} S&=\frac{QK^\top}{\sqrt{d_k}}+M\in\mathbb{R}^{n\times n},\\ A&=\operatorname{softmax}(S)\in\mathbb{R}^{n\times n},\\ O&=AV\in\mathbb{R}^{n\times d_v}. \end{aligned} \]

其中 \(M\) 是 causal mask（因果掩码）。对 decoder self-attention，若 key 位置 \(j\) 在 query 位置 \(i\) 的未来（\(j>i\)），令 \(M_{i,j}=-\infty\)。softmax 后该位置权重为 \(0\)；这保持“第 \(i\) 个预测只使用已知输出”。

\(1/\sqrt{d_k}\) 的目的不是装饰：论文指出，在 \(q\) 与 \(k\) 分量独立、均值为 \(0\)、方差为 \(1\) 的简化假设下，\(q^\top k\) 的方差为 \(d_k\)。不缩放时，较大的 score 容易使 softmax 进入梯度很小的区域。

把机制放回因果链

问题
RNN 的 \(h_t\) 依赖 \(h_{t-1}\)，样本内 token 必须按顺序计算。
↓
改动
用矩阵乘法同时得到每个 token 对所有 token 的相容度 \(QK^\top\)。
↓
为何有效
任意位置在一层内都有直接连接；所有 score 可由一次批量矩阵乘法计算。
↓
代价
要显式处理 \(n\times n\) 的 pairwise scores；长上下文优化正是沿着此处继续展开。
