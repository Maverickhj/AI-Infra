Lesson 0008 · 约 15 分钟

Why Self-Attention：三种成本不能混为一谈

Lesson 1 已经建立“用全位置 pairwise computation 移除 RNN 串行递推”的直觉。本课进一步还原论文 §4 的正式比较：per-layer complexity、minimum sequential operations 与 maximum path length 是三个不同指标，不存在一个脱离 \(n\)、\(d\) 与硬件条件的“attention 永远更快”。

前置：课程 0007 · 速查：Attention 因果链 · 术语：Complexity terms · 主证据：Vaswani et al. (2017), §4, Table 1

设计问题：用哪三把尺评价 sequence layer？

论文比较的是把一组 \(n\) 个 \(d\)-dimensional representations 映射为另一组等长 representations 的 layer。作者提出三项 desiderata（期望性质）：

Per-layer complexity：完成一层理论上需要多少 arithmetic operations？

Minimum sequential operations：存在数据依赖时，最少必须串行经过多少 computation steps？

Maximum path length：任意两个 positions 之间的信息或 gradient 最多经过多少层 computational-graph edges？

第一项描述总工作量；第二项描述可并行化边界；第三项描述远距离信息交互所需的 network depth。总工作量小，不自动表示串行步骤少；串行步骤少，也不自动表示实际 wall-clock latency 低。

论文 Table 1：先定义符号，再读结论

令 \(n\) 为 sequence length，\(d\) 为 representation dimension，\(k\) 为 convolution kernel size，\(r\) 为 restricted self-attention 的 neighborhood size。论文给出的 asymptotic comparison 为：

Layer typeComplexity per layerSequential operationsMaximum path length
Self-Attention\(O(n^2d)\)\(O(1)\)\(O(1)\)
Recurrent\(O(nd^2)\)\(O(n)\)\(O(n)\)
Convolutional\(O(knd^2)\)\(O(1)\)\(O(\log_k n)\)
Self-Attention (restricted)\(O(rnd)\)\(O(1)\)\(O(n/r)\)
表格范围：这些是 2017 论文为 layer types 给出的 asymptotic expressions，不包含具体 kernel efficiency、memory traffic、launch overhead、activation memory、batching、communication 或现代 optimized implementations。

为什么论文说 \(n<d\) 时 self-attention 更省计算？

只比较 Table 1 中 full self-attention 与 recurrent layer 的主导项：

\[ \begin{aligned} C_{\text{attn}}&\propto n^2d,\\ C_{\text{rnn}}&\propto nd^2. \end{aligned} \]

令 self-attention 的理论计算量更小：

\[ \begin{aligned} n^2d&<nd^2\\ n&<d. \end{aligned} \]

所以论文的结论有明确条件：当 sequence length \(n\) 小于 representation dimension \(d\) 时，self-attention 的该主导项小于 recurrent layer。原论文认为当时 machine translation 的 sentence representations 通常处于这个区域。

当 \(n>d\) 时，上述 inequality 反转。此时不能再用论文的这条算术比较声称 full attention 更省总计算；而且 attention score tensor 的 \(n\times n\) size 还会带来 quadratic memory pressure。

\(O(1)\) sequential operations 到底意味着什么？

在一个 full self-attention layer 内，所有 positions 的 Q/K/V 与 pairwise scores 可以组织成 batched matrix operations，不需要像 RNN 那样等待：

\[ h_t=f(h_{t-1},x_t). \]

因此论文把 self-attention 的 minimum sequential operations 记为 \(O(1)\)，把 recurrent layer 记为 \(O(n)\)。这里的 \(O(1)\) 表示 layer computation graph 没有随 sequence length 增长的 token-to-token recurrence chain，不表示整个计算只需一个 machine instruction。

不要跨越边界：这一指标描述 training / full-sequence layer evaluation 的并行结构。Autoregressive inference 仍必须先生成 \(y_t\)，才能把它作为 prefix 的一部分生成 \(y_{t+1}\)。

Maximum path length 为什么影响 long-range dependency？

这里的 path length 不是 token distance 本身，而是信息与 backward signal 在 computational graph 中，从一个 position 到另一个 position 要经过的最大 edge 数。

Layer family跨远距离 position 的路径结果
RNN必须沿 hidden states 逐步传播maximum path length 为 \(O(n)\)
full self-attention任意 query 可直接连接任意 keymaximum path length 为 \(O(1)\)
local / restricted attention每层只能跨 neighborhood \(r\)需要多层传播，得到 \(O(n/r)\)

论文据此提出：更短的 forward / backward paths 可能让 long-range dependencies 更容易学习。这里是 architecture-level motivation，不是“只要路径为 \(O(1)\)，模型就必然学会所有长距离关系”的保证。

Convolution 与 restricted attention 的交换条件

一个 kernel width 为 \(k<n\) 的 convolutional layer 不能直接连接所有 position pairs。论文正文进一步区分：

\[ \begin{aligned} \text{contiguous convolution path} &=O(n/k),\\ \text{dilated convolution path} &=O(\log_k n). \end{aligned} \]

Table 1 在 Convolutional 一行列出 \(O(\log_k n)\)。这是使用 dilated stacking 缩短路径的结果；不要把它误读成任意单层 ordinary convolution 都能直接全局通信。

restricted self-attention 把每个 position 的可见范围限制在 size \(r\) 的 neighborhood：

\[ O(n^2d) \quad\longrightarrow\quad O(rnd), \qquad O(1) \quad\longrightarrow\quad O(n/r) \]

它以更长的 cross-position path 换取更低的 long-sequence computation。论文把它写成未来可研究的方向；原始 Transformer 使用的是 full attention，不能把 restricted row 当成论文实验配置。

“更可解释”在论文中是什么证据等级？

论文将 interpretability 写作 self-attention 的一个 possible side benefit，并在 appendix 展示 attention distributions：一些 heads 看起来与 long-distance dependencies、anaphora 以及 syntactic / semantic structure 有关。

证据边界：这是对 learned attention patterns 的 qualitative inspection。它支持“不同 heads 出现了可观察的结构化模式”，但不能单独证明 attention weights 是模型决策的完整 causal explanation。
