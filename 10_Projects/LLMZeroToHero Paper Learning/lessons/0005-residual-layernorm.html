Residual Connection 与 LayerNorm：如何把 sub-layers 堆深？

attention 负责跨 positions 交换信息，FFN 负责逐 token 变换 representation。但若每个 sub-layer 都直接覆盖输入，深层模型中的已有信息和数值尺度会不断被重写。原始 Transformer 用 Residual Connection（残差连接）保留一条 additive path，再用 Layer Normalization（层归一化）调整每个 token 的 feature distribution。

前置：课程 0004 · 数学：LayerNorm 数学起步 · 术语：Attention Glossary · 主证据：Vaswani et al. (2017), §§3.1, 5.4

先从“直接覆盖”留下的问题出发

设一个 attention 或 FFN sub-layer 为 \(F\)。若直接写成 \(x^{l+1}=F(x^l)\)，下一层只能看到 \(F\) 重新计算后的结果；即使原来的 \(x^l\) 已包含有用 information，也必须由 \(F\) 再次重建。

Residual Connection 改为先相加：

\[ u=x+F(x). \]

于是 \(F\) 可以被理解为学习一个 update / residual（更新量），而 \(x\) 提供直接的 additive path。若当前 sub-layer 暂时不需要改变某些信息，\(F(x)\) 可以在相应方向上接近 \(0\)，而不必重新生成整个 \(x\)。

解释边界：“学习 update、保留直接路径”是理解 residual 的数学视角。原始 Transformer 明确给出了 residual 结构，但没有在 §3.1 中证明它必然解决所有深层优化问题。

为什么前几课一直回到 \(d_{\mathrm{model}}\)？

element-wise addition（逐元素相加）要求两侧 shape 完全一致：

\[ x,\ \operatorname{Sublayer}(x),\ x+\operatorname{Sublayer}(x) \in\mathbb{R}^{n\times d_{\mathrm{model}}}. \]

这解释了两个此前见过的设计：

  • Multi-Head Attention 在 Concat 后用 \(W^O\) 投影回 \(d_{\mathrm{model}}\)；
  • FFN 从 \(d_{\mathrm{model}}\) 扩展到 \(d_{\mathrm{ff}}\) 后，再投影回 \(d_{\mathrm{model}}\)。

它们都必须满足统一的 residual interface。原论文也明确说明，为了 residual connections，所有 sub-layers 与 embedding layers 的输出维度均为 \(d_{\mathrm{model}}=512\)。

LayerNorm 在归一化什么？

对某个 token position \(i\) 的 vector \(x_i\in\mathbb{R}^{d_{\mathrm{model}}}\)，LayerNorm 沿该 token 的 feature dimension 计算 mean 与 variance：

\[ \begin{aligned} \mu_i&=\frac{1}{d_{\mathrm{model}}}\sum_k x_{i,k},\\ \sigma_i^2&=\frac{1}{d_{\mathrm{model}}}\sum_k(x_{i,k}-\mu_i)^2,\\ \operatorname{LN}(x_i)_k&=\gamma_k\frac{x_{i,k}-\mu_i}{\sqrt{\sigma_i^2+\epsilon}}+\beta_k. \end{aligned} \]

也就是说，每个 token 有自己的 \(\mu_i\) 与 variance；它不使用其他 batch examples 的统计量，也不沿 sequence positions 求一个共同 mean。\(\gamma\)、\(\beta\) 是按 feature 学习的 gain 与 bias。

不要误读：标准化后的中间量均值约为 0、variance 约为 1；再经过 learned γ、β 后，LayerNorm 最终输出不必仍严格满足零均值、单位方差。公式中的 ε 是实现中避免除零的数值保护项。

原始 Transformer 的顺序是 Post-LN

2017 论文对每个 sub-layer 使用：

\[ y=\operatorname{LayerNorm}(x+\operatorname{Sublayer}(x)). \]

LayerNorm 位于 residual addition 之后，因此这种排列后来通常称为 Post-LN（后归一化）。若把 training-time dropout 写完整，则是：

\[ y=\operatorname{LayerNorm}\left(x+\operatorname{Dropout}(\operatorname{Sublayer}(x))\right). \]

原论文 base model 的 dropout rate 为 0.1；inference 时 dropout 关闭。Dropout 是 regularization（正则化），不能把它与 LayerNorm 的数值归一化职责混为一谈。

重要边界：若 \(\operatorname{Sublayer}(x)=0\)，Post-LN 输出为 \(\operatorname{LayerNorm}(x)\)，而不是字面上的 \(x\)。因此 residual addition 提供了直接的 additive path，但经过后置 LayerNorm 后，整个 block 并非严格 identity mapping。

不要把原论文和现代 Pre-LN 混在一起

排列公式本课程中的证据边界
Post-LN\(\operatorname{LN}(x+\operatorname{Sublayer}(x))\)原始 Attention Is All You Need 的结构。
Pre-LN\(x+\operatorname{Sublayer}(\operatorname{LN}(x))\)许多后续 Transformer / LLM 使用的变体；不是原论文 §3.1 的公式。

二者都含 residual 与 normalization，但 normalization 的位置改变了 forward path 与 gradient path。当前只需能识别原论文是 Post-LN；更深模型为何大量转向 Pre-LN，留到后续论文的因果链中讨论。

把完整 layer 拼起来

Stacksub-layers 的顺序
Encoder layerself-attention → Add & Norm → FFN → Add & Norm
Decoder layermasked self-attention → Add & Norm → cross-attention → Add & Norm → FFN → Add & Norm

这里每个 arrow 后传递的 shape 都保持 \([\text{sequence length},d_{\mathrm{model}}]\)。attention 改变跨 positions 的信息组合，FFN 改变逐 position 的 features，Residual Connection 与 LayerNorm 则让这些 sub-layers 能以统一接口反复堆叠。
