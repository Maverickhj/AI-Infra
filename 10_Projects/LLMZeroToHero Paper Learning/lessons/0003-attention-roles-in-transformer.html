Encoder、Decoder 与 Cross-Attention

前两课解释了 attention 如何计算、多个 heads 为什么有用。这一课只回答一个架构问题：同一套 attention 公式，为何在原始 Transformer 中要以三种不同的 Q/K/V 来源出现？

前置：课程 0002 · 术语：Attention Glossary · 主证据：Vaswani et al. (2017), §§3.1, 3.2.3

先还原原始 Transformer 的任务

原论文的 Transformer 是一个 Encoder–Decoder sequence-to-sequence model。Encoder 把完整 input sequence \(x_{1:n}\) 映射为 contextual representations \(E[n,d_{\mathrm{model}}]\)；Decoder 在 \(E\) 的条件下，一次生成一个 target token \(y_i\)。

input sequence
\(x_{1:n}\) → Encoder → \(E\)（source memory）
↓
target prefix
\(y_{<i}\) → Decoder masked self-attention → \(D\)（当前 generation state）
↓
condition on input
\(Q\) from \(D\), \(K/V\) from \(E\) → cross-attention → predict \(y_i\)

关键不是记住三种名称，而是每次先问：query 在问什么？key/value 是哪一份 memory？哪些位置允许可见？

从条件概率推导 Cross-Attention

翻译、摘要等 sequence-to-sequence task 想学习的不是“根据已写出的 target 续写”，而是：

\[ p(y\mid x)=\prod_i p(y_i\mid y_{<i},x). \]

生成第 \(i\) 个 target token 时，模型同时需要两类、性质不同的信息：target prefix 告诉它“我已经写到哪里、下一步在句法和语义上缺什么”；完整的 source \(x\) 提供事实、实体与对应片段。两者不能互相替代。

只有 Decoder masked self-attention
每个位置只能从 \(y_{<i}\) 读取信息；这最多是 \(p(y_i\mid y_{<i})\)。source \(x\) 没有进入该信息路径。
↓
需要一份可查询的 source memory
Encoder 先把完整 x 编码为 E；E 保留各个 source position 的 contextual information。
↓
由当前 target state 发起读取
当前 \(D_i\) 形成 \(Q_i\)，在 \(E\) 的 \(K/V\) 中选择和聚合信息，补上条件 \(x\)。
最小判断：若 cross-attention 的 \(Q/K/V\) 都来自 Decoder，结果仍只是 masked self-attention，模型没有任何从 \(x\) 到 \(y\) 的路径；它不能实现条件生成 \(p(y\mid x)\)。

为什么由 Decoder 提 Q、Encoder 提 K/V？

在 target position \(i\)，Decoder state \(D_i\) 是“已生成 prefix 后的当前需求”。把它投影成 \(Q_i\)，可以理解为一次按需检索：此刻为了预测 \(y_i\)，source 中哪些位置相关？

Encoder 的每个 position \(E_j\) 则提供可被检索的 source memory。\(K_j\) 像可匹配的 address（地址），\(V_j\) 是一旦选中后要带回的 content（内容）。\(Q_iK_j^\top\) 为第 \(i\) 个 target position 对第 \(j\) 个 source position 计算相关度，softmax 后再加权聚合 \(V\)。

因此，attention 输出更新的是 query 所在的一侧：\(Q\) 来自 Decoder，就得到“带有 source 条件的 target representation”，正好供 \(y_i\) 的预测使用。若反过来让 Encoder 提 \(Q\)、Decoder 提 \(K/V\)，更新的会是 source representation 对不完整 target history 的读取，不能直接回答当前 target position 要生成什么。

一项直接的工程结果：\(E\) 以及它投影出的 \(K/V\) 在整个 decoding 过程中不变，可复用；每一步随 target prefix 改变的是 \(D_i\) 与 \(Q_i\)。这是该信息分工带来的效率收益，不是 \(Q/K/V\) 来源的唯一理由。

三种 attention 的 Q/K/V 来源

位置Q 来源K/V 来源可见性与职责
Encoder self-attentionEncoder 上一层表示同一份 Encoder 上一层表示每个 input position 可读全部 input positions，建立 source-side context。
Decoder masked self-attentionDecoder 上一层表示同一份 Decoder 上一层表示位置 \(i\) 只能读 target positions \(\le i\)；causal mask 防止读取未来 target。
cross-attention
（encoder-decoder attention）		Decoder masked self-attention 的输出Encoder stack 的输出 E每个 Decoder position 可读全部 input positions；把当前 target-side need 对齐到 source memory。
最容易混淆的边界：cross-attention 不需要 mask source positions，因为完整 input 在生成前已经给定；Decoder 不能偷看未来 target，靠的是它前面的 masked self-attention，而不是 cross-attention。

cross-attention 的形状

在 teacher-forcing training 中，可同时处理 \(m\) 个 target positions；但每一位置的依赖约束仍由 causal mask 保证。令 Decoder 当前表示为 \(D[m,d_{\mathrm{model}}]\)，Encoder memory 为 \(E[n,d_{\mathrm{model}}]\)：

下式省略 head index，描述一个 head；原始 Transformer 实际并行执行多个 heads，再 Concat 并经 \(W^O\) 融合。

\[ \begin{aligned} Q=DW^Q&\in\mathbb{R}^{m\times d_k},\\ K=EW^K&\in\mathbb{R}^{n\times d_k},\\ V=EW^V&\in\mathbb{R}^{n\times d_v},\\ S=QK^\top&\in\mathbb{R}^{m\times n},\\ A=\operatorname{softmax}(S)&\in\mathbb{R}^{m\times n},\\ O=AV&\in\mathbb{R}^{m\times d_v}. \end{aligned} \]

\(S\) 的第 \(i\) 行是“第 \(i\) 个 target position 对所有 \(n\) 个 input positions 的 attention scores”。因此 cross-attention 的矩阵不是 \([m,m]\)，而是 \([m,n]\)。

用一个翻译位置检查信息流

假设 input 是 “我 喜欢 猫”，target 正在生成英文第 2 个位置。该位置的 Decoder state 可以从之前已生成的 target prefix 取得语言侧上下文；随后 cross-attention 以这个 state 为 query，在 Encoder 对 “我 / 喜欢 / 猫” 的完整 memory 中选择信息。

它可以对 source 的任意位置分配 weight，但不能通过此路径读取未来的 target token。对 source 的全局可见性与对 target 的因果可见性，是两个独立约束。
