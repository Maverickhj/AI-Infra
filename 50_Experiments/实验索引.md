# 实验索引

实验用于把静态代码推断升级为可复现证据。失败实验同样保留，因为它能约束后续结论。

## 新建实验

使用 [[90_Templates/Experiment|Experiment 模板]]，文件名采用：

```text
EXP-YYYYMMDD-<short-name>.md
```

## 最小可复现要求

- 问题或假设。
- 仓库与 commit、镜像/依赖、hardware。
- 模型、数据、输入规模和并行拓扑。
- 精确命令与环境变量（排除 secrets）。
- 原始观测、指标定义与 artifact 路径。
- 解释、局限和下一步。
