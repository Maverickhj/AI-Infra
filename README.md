# AI-Infra

面向大模型工程师的个人知识库，核心覆盖 Transformer、分布式训练、推理系统、LLM 强化学习、多模态与生产故障排查。

它不是一组静态教程，而是一套会随着资料、实验和问题持续生长的工程 Wiki：原始输入保持不变，可复用结论进入知识笔记，操作经验沉淀为 Runbook，关键选择进入 ADR，所有入口由 MOC 与总索引维护。

## 核心原则

1. 先建立可解释的张量与系统模型，再记配置和结论。
2. 代码问题追到真实 producer、转换、进程边界与 consumer。
3. 明确区分已验证事实、推导、推断、建议与待核验项。
4. 一次问题如果产生可复用结论，就把它编译回 Wiki。
5. 原始资料不可改；知识层允许随着新证据修订，并保留冲突。
